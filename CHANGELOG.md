# Changelog

## 0.1.1

- Rename the extension and its user-facing labels to Smart Profiles.
- Make the icon corners transparent and refresh the demonstration.

## 0.1.0

- Select profiles from top-level repositories, excluding nested dependencies and
  submodules unless opened as their own workspace root.

- Select profiles using Git remote hosts, folder globs, project files, and
  standalone file extensions.
- Keep mixed or unmatched workspaces unchanged.
- Add user-only rules, decision explanations, manual reapplication, and a
  workspace pause command.
